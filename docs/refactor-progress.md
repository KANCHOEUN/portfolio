# 포트폴리오 리팩토링 결과

2026-10-03에 승인한 계획을 기존 작업 폴더에 적용했습니다. 커밋·배포와 Mockly 서버 수정은 수행하지 않았습니다.

## 변경 내용

- 한국어 프로필과 프로젝트 메타데이터를 분리하고, 언어 Provider·영어 번역·언어 이벤트를 제거했습니다. 문서 언어는 `ko`입니다. `language` 저장값을 읽는 경로가 없어 기존 `language=en`이 화면에 영향을 주지 않습니다.
- 사이드바·이력서·탭은 동일한 프로젝트 등록 데이터를 사용합니다. 기존 페이지 ID와 주소를 유지하고, RE-VERSE/PARSLEY 기간과 Mockly/Pigrest 상태를 통일했습니다.
- Mockly Outbox의 커밋 후 최초 즉시 처리와 실패 후 스케줄러 재시도, 비동기 피드백의 트랜잭션 분리·재시도·복구를 실제 서버 코드에 맞춰 설명했습니다. 검증되지 않은 개선 수치는 추가하지 않았습니다.
- Notion 코드·수식·컬렉션 렌더러를 연결하고 테마를 동기화했습니다. 페이지별 요청 공유, 성공 결과 5분 캐시, 오류 재시도와 원문 링크를 제공합니다. iframe에는 원래 인코딩된 URL을 그대로 전달합니다.
- URL을 활성 페이지의 기준으로 삼고 탭 목록과 글 뷰어 상태를 분리했습니다. 탭 선택·닫기는 replace, 사이드바는 push를 사용합니다. 마지막 탭을 닫으면 글 뷰어와 편집기 내용을 비웁니다.
- 편집기를 상태 관리·탭 헤더·프로젝트 렌더러·글 뷰어로 나누고 React context/콜백으로 글 열기를 연결했습니다.
- 내비게이션·접기/펼치기·탭을 키보드로 조작할 수 있도록 정리했습니다. 이미지 확대는 이름 있는 닫기 버튼·Escape·포커스 복귀를 제공합니다. 탭을 닫아도 남은 탭 또는 빈 편집기로 포커스가 이동합니다.
- 모바일에서 글을 연 채 다른 프로젝트로 이동하면 선택한 프로젝트를 표시하도록 수정했습니다.
- 테마 Provider와 의미별 CSS 변수를 통합하고 중복/전역 보정 스타일을 제거했습니다. 입자는 문서 비활성화·모션 감소에서 멈추고 모바일에서 수를 줄입니다.
- 사용 경로가 없는 구형 프로젝트 컴포넌트·UI·언어 파일·설정·폰트를 제거했습니다. npm lockfile 하나로 통일하고 ESLint flat config·typecheck·format 명령과 README를 정리했습니다.
- Next.js 15.5.27과 sharp 0.35.5로 실제 감사 결과의 취약점을 수정했습니다. Next.js 하위 PostCSS를 수정된 8.5.28과 일치시키고 전이 의존성을 갱신했습니다. npm 설치 감사 결과는 0건입니다.

## 성능과 미디어

- GIF 13개: 315.08 MiB → MP4 + WebP 4.77 MiB, **98.49% 감소**.
- 기존 음성 채팅 MP4까지 포함한 전체 데모: **319.34 MiB → 9.04 MiB, 97.17% 감소**.
- H.264·최대 1280px·15fps·CRF 28로 인코딩했습니다. 모든 재생 시간은 원본과 0.15초 이내이며, 프레임과 실제 재생을 확인했습니다. 프로필·스터디룸·글 작성 화면의 글자를 읽을 수 있습니다.
- 영상은 controls/playsInline/preload="none"으로 자동 재생하지 않습니다. 브라우저에서 재생 전 readyState 0, 재생한 영상만 readyState 4가 되는 것을 확인했습니다. 관측된 자산에 GIF 요청이 없습니다.
- 로컬 이미지는 실제 크기와 Next Image 최적화를 사용하며 확대에서는 원본을 제공합니다.
- `/portfolio` 첫 로드 JS: 161 kB → 134 kB. 페이지 자체 JS: 47.8 kB → 19.8 kB. 빌드가 출력한 경로 단위 값으로, 실제 사용자 네트워크 속도 측정값은 아닙니다.

개별 파일의 용량·길이·해상도는 `media-optimization.json`에 기록했습니다.

## 검증

- `npm ci`: 깨끗한 설치 성공, 감사 취약점 0건.
- `npm test`: 기존 Notion 테스트를 포함한 10개 통과.
- `npm run test:notion:integration`: 실제 공개 Notion 페이지 조회 1개 통과.
- `npm run typecheck`, `npm run lint`, `npm run build`: 통과. 타입/린트 오류 무시 설정을 제거했습니다.
- 데스크톱과 390px 모바일에서 양쪽 테마, 내비게이션, 탭 키보드 선택/닫기, 마지막 탭, URL의 뒤로 가기/새로고침, 잘못된 ID, 글 뷰어, 확대 이미지와 영상 재생을 확인했습니다.
- 실제 Notion 글에서 코드 블록 5개가 표시되고 경고 로그가 없는 것을 확인했습니다. 오류·재시도·진행 중 요청 공유·캐시 만료는 단위 테스트로 검증했습니다.
- 별도 코드 리뷰의 모바일 이동·탭 닫기 포커스 지적을 수정하고 브라우저에서 재검증했습니다.
- 기존 미커밋 Notion API·공개 클라이언트·테스트 4개 파일은 작업 전 백업과 바이트 단위로 일치합니다.

## 판단과 제약

- 기존 미커밋 작업을 보존하기 위해 승인된 현재 checkout에서 작업했습니다. 원래 소스는 `/private/tmp/portfolio-refactor-baseline`에 백업했습니다.
- 공유 Notion 요청은 한 뷰어가 닫힌다고 취소하지 않습니다. 뷰어는 늦은 결과를 무시하고 네트워크 요청에는 시간 제한을 적용합니다.
- 기존 한국어 활동 기록과 2022년 수상을 근거로 SSAFY 교육 기간을 2022.01–2022.12로 정정했습니다.
- 설치된 ffmpeg에 libwebp가 없어 프레임을 추출한 뒤 sharp로 WebP 포스터를 생성했습니다. 결과 형식과 품질 검증 기준은 유지했습니다.
- npm이 기존 의존성 트리에서 새 PostCSS override를 반영하지 않아, 직접 의존성 버전을 고정하고 트리를 백업한 뒤 lockfile을 다시 생성했습니다. 새 lockfile의 npm ci 재현성을 확인했습니다.
- Notion 공개 권한·공개 API 응답 변경, 외부 사이트의 iframe 제한과 장애는 서비스 측 제약입니다. 실패 시 재시도와 원문 링크를 제공합니다.
- react-notion-x의 일부 전이 의존성이 오래된 React peer 범위를 선언하여 npm 설치 경고가 남습니다. 현재 React 19에서 빌드·코드 블록·이미지·글 표시를 확인했습니다. upstream 업데이트 시 다시 검증해야 합니다.
