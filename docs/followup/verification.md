기존 미커밋 리팩토링과 병렬 후속 작업을 함께 검증했다. 공개 Notion 클라이언트·API와 기존 단위 테스트를 유지했으며 Mockly 서버는 변경하지 않았다. 독립 리뷰의 유일한 P2 지적은 동일한 뷰어를 유지하는 지연 응답 테스트와 실제 실패를 확인한 취소 조건 제거 실험으로 해결했다.

전체 브라우저 검증은 `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3100 npm run test:e2e -- --output=/private/tmp/portfolio-final-browser-green`으로 프로덕션 빌드와 로컬 Chrome에서 실행했다. 30개 조합 중 제외한 세 경우는 데스크톱의 모바일 전용 이동, 모바일의 탭과 글 동시 표시, 모바일의 열린 글을 유지한 다른 글 링크 선택이다. 각 화면에서 제공되는 대응 동작은 별도 사례로 검증했다.

Notion은 HTTP 데이터만 고정하고 실제 Code·Equation·Collection 렌더러를 실행한다. 공개 서비스 통합 테스트는 별도로 실제 응답을 확인한다. 모바일 초기 화면 너비, 양쪽 테마, 한국어 전용 동작, URL·뒤로 가기·새로고침·탭 닫기·키보드·이미지 확대·영상 재생과 재생 전 다운로드를 포함한다.

남은 전체 감사 항목 9건은 Tailwind 3/ESLint 개발 도구 경로에 있다. 호환 가능한 수정이 없으므로 강제 설치나 경고 숨김은 사용하지 않았다. 내용과 관련 버전은 [의존성 보고서](dependencies.md)에 기록했다. 공개 Notion 권한·응답 변경, iframe 제공 사이트 정책과 외부 장애는 앱만으로 보장할 수 없다.

프로덕션 빌드의 `/portfolio` 초기 JS는 134kB이며 `/about`은 119kB, `/resume`은 118kB였다. 이는 Next 빌드의 초기 JS 집계이며, 실제 첫 화면 전송량이나 사용자 성능 수치는 [성능 보고서](performance.md)에서 별도로 다룬다.
